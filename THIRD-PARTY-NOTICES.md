# Third-party components

BO2Z-Offline builds with these vendored open-source components. Their source
directories retain their original copyright notices and license texts.

- **LibTomCrypt 1.18.2** — public-domain/Unlicense terms in
  [`external/libtomcrypt/LICENSE`](external/libtomcrypt/LICENSE).
- **zlib** — zlib license in [`external/zlib/README`](external/zlib/README).

BO2's executable is not included. The nine BO2 publisher resources required
by the current offline build are included under `resources/publisher/` and in
the install ZIP. These game files, the BO2 franchise, trademarks, and artwork
remain the property of their respective owners and are not covered by the
project's Apache 2.0 code license.
